But what is it actually?

A voting engine with payments built in.

The site sells votes like a product catalogue, but the backend behaves like a payment system: initialize, verify, credit once, report instantly.

01

Select contestant

User picks a nominee and vote package. Amount is calculated on the backend.

02

Initialize payment

Backend creates a unique reference and sends the user to Paystack checkout.

03

Verify webhook

Webhook signature and transaction status are verified before crediting votes.

04

Credit tally

Votes are added once using idempotency, then reports and rankings update.
